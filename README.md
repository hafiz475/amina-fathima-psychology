# Syed Amina — Counselling Psychologist Practice Website

Official professional portfolio and appointment booking platform for **Syed Amina**, Counselling Psychologist (M.Sc. Counselling Psychology).

## 🌿 Overview

A responsive, accessible web platform built to provide psychoeducation, clarify clinical and therapeutic approaches, detail practice credentials, and facilitate confidential booking inquiries.

- **Practice**: Individual counselling, adolescent & youth mental health, emotional wellness, workplace mental health
- **Approach**: Person-centred, Cognitive Behavioural Therapy (CBT), Acceptance & Commitment Therapy (ACT), trauma-informed care
- **Framework**: Next.js (App Router), TypeScript, SCSS design system, Tailwind CSS, Lucide React

## 🚀 Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: SCSS Design Tokens (`src/styles/`) & Tailwind CSS
- **Typography**: Manrope
- **Icons**: Lucide React
- **Animations**: Framer Motion & CSS Micro-interactions

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application in the browser.

### 3. Build for Production
```bash
npm run build
npm run start
```

## 📁 Key Architecture

- `src/app/` — App Router pages (Home, About, Services, Approach, Experience, Resources, Booking, Contact)
- `src/components/layout/` — Navbar, Footer, Mobile Navigation
- `src/components/hero/` — Hero section & SVG brand visuals
- `src/components/sections/` — Interactive practice sections
- `src/components/ui/` — Accessible primitives (modals, cards, accordions)
- `src/data/` — Practice credentials, services, approach methodologies, FAQs
- `src/styles/` — Custom design system tokens (`variables.scss`, `sections.scss`)
